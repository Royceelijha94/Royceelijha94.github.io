slo-forgeGitHub ↗

      
A Python CLI that turns a six-line YAML spec into correct multi-window, multi-burn-rate SLO alerting for Prometheus, and refuses to generate rules that can never fire.

      
    
        
  • Fast (14.4×, pages) and slow (6×, ticket) burn alerts per objective, following the Google SRE Workbook method

  • Catches five silent failure modes Prometheus never reports: integer-truncated budgets, unguarded division by zero, unreachable thresholds, missing histogram buckets, single-window alerts
    • 
        
  • 25 unit tests, CI that lints output with promtool, and a kind demo that injects a 40% error rate to show the budget burn end to end
